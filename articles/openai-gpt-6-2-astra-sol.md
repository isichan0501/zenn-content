[November 17, 2026] OpenAI announced the general availability of GPT-6.2 Astra and GPT-6.2 Sol, the latest iterations of its frontier model lineup. Both models are now available in GitHub Copilot and the OpenAI API.

GPT-6.2 Astra is positioned as a model for advanced reasoning, coding, and complex professional work. In early testing, Astra demonstrated significantly better code-review issue detection than GPT-6 Astra while using fewer output tokens. The model excels at creating slides, spreadsheets, and documents that follow templates more closely, and shows improved performance in website coding, gaming, and 3D design tasks.

GPT-6.2 Sol combines speed with lower cost, offering nearly double the real-code-review issue detection of GPT-6.1 Sol while maintaining accuracy. Sol is designed for complex agentic coding and in-depth code review workloads. Both models accept text and image inputs and return text output, priced under the Standard API rates.

Developers can access both models via the `gpt-6.2-astra` and `gpt-6.2-sol` endpoints using the Responses or Chat Completions API. OpenAI notes that early testing shows both models complete agentic coding tasks using fewer tokens compared to their predecessors, though release benchmarks do not establish savings on individual workloads.

**Model availability**: GPT-6.2 Astra and GPT-6.2 Sol are available through the OpenAI API and GitHub Copilot. Enterprise and Edu access require administrator enablement.
